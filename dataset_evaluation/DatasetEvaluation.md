# Dataset Evaluation: Scene Understanding (COCO vs. SA-1B)

## 1. Use Case

Scene understanding is the computer vision task of localizing, segmenting, and recognizing the multiple objects that co-occur in natural, everyday scenes.
It is essential for intelligent systems because acting in real environments requires knowing not only where an object is located, but also which semantic category it belongs to.
The main difficulty lies in non-canonical viewpoints, occlusions, and cluttered scenes, which simplified, object-centric benchmarks do not capture.
We selected this use case because applications such as robotics, autonomous navigation, and assistive technologies depend on models trained on complex, realistic scenes rather than on isolated, centered objects.
A suitable dataset therefore needs realistic multi-object scenes, semantically labeled objects, and precise, correct object boundaries.

## 2. Most Important Criteria

The three most important criteria, in this order, are Task Specificity (Annotation Planning), Careful Data Selection (Data Sourcing), and Error Rate (Quality Assurance).
First, Task Specificity is essential because scene understanding requires an explicit semantic category for each object; class-agnostic masks show where something is, but not what it is.
Second, Careful Data Selection is critical because the images must show complex, non-iconic multi-object scenes and should be checked for bias, so that models do not overfit to canonical views or to a narrow part of the world.
Third, Error Rate is indispensable because dense scenes with occlusions require precise boundaries, and only an error rate measured on the final dataset shows how much annotation noise a model would learn from.

In the tables below, *Use Case Priority* 1 marks these three main criteria; 2 marks criteria that directly affect the quality or usability of the data for this use case; 3 marks documentation and method details, aspects with only indirect influence, and criteria that only serve to interpret agreement values (neither dataset reports inter-annotator agreement); N/A marks criteria that do not apply to the use case.

## 3. Comparison

| Main criterion | COCO | SA-1B | Better |
|---|---|---|---|
| 1. Task Specificity | High: 91 categories, per-instance masks | Low: no categories | COCO |
| 2. Careful Data Selection | Deliberately non-iconic multi-object scenes; no bias check, mainly North America and Europe | No documented selection criteria; geography and income analyzed | Tie |
| 3. Error Rate | None for the final masks | Proxy: 94% of mask pairs (automatic vs. corrected) > 90% IoU | SA-1B |

COCO is the most suitable dataset for scene understanding, because it clearly wins the top-ranked criterion: its objects carry semantic categories and individual masks, whereas SA-1B has no categories and therefore cannot teach a model to recognize objects.
In data selection, both have different strengths: COCO deliberately selected non-iconic multi-object scenes but was not checked for bias (according to the SA-1B paper, its images come mainly from North America and Europe), while SA-1B lacks documented selection criteria but was analyzed for geographic and income coverage.
SA-1B is better on Error Rate, since its masks were compared with professionally corrected versions, whereas COCO accepts each mask on crowd votes alone.
SA-1B's lower suitability thus results from its design for class-agnostic segmentation, not from poor annotation work; in criteria such as privacy and the documentation of working conditions, it even outperforms COCO.
Note that the result is largely decided by the first criterion and that our use case follows the goals COCO was designed for.
